# Roblox Viruses
Archive of Roblox viruses using .rbxm files you can import into using Roblox Studio. These were found off of public free models inside of the Toolbox, their names usually start with an emoji. They have been edited to be more readable.
Some of them had scripts or instances that crashed/freezed Studio, but I removed them. Some scripts are obfuscated, which I couldn't deobfuscate. There are some executors in there.
